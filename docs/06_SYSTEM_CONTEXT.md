# System Context

## Purpose

RescueMap OS is an open-source disaster response support platform.

The system helps citizens, vulnerable populations, institutions, and local governments share disaster-related status information and location clues.

## Primary Users

### Citizens

- Submit status updates
- Share location clues
- Check nearby shelters
- Access disaster response guidance

### Vulnerable Users

- Elderly
- Children
- Disabled individuals
- Mobility-limited users

### Institutions

- Welfare centers
- Schools
- Local governments
- Emergency response teams

### Community Volunteers

- Monitor requests
- Assist information sharing
- Support post-disaster reporting

## Core Interaction

Citizen
→ Status Report
→ Backend
→ Institution Dashboard
→ Follow-up Action

## Current Scope

RescueMap OS provides:

- Status sharing
- Location clue recording
- Failure-map reporting
- Open-source disaster kits

## Out of Scope

- Medical diagnosis
- Real-time rescue command
- Autonomous decision making
- Guaranteed emergency response
