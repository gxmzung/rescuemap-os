# StellaVision Coffee Chat Memo

## 1. Why This Project Is Relevant

RescueMap OS connects disaster response, map data, public data, risk layers, and situational dashboards.

This is relevant to a broader interest in satellite data, SAR, spatial information, and decision-support systems.

## 2. How To Explain It

Recently, I started preparing an open-source project called RescueMap OS.

At first, I considered AI-based disaster guidance, but I concluded that letting AI directly guide people through buildings during a disaster could be ethically and technically risky.

So I redesigned the project around a safer idea:

- leave the user's last location and status
- record building/floor/zone clues
- support vulnerable users
- help guardians and institutions check status
- generate post-disaster failure maps

In the future, this could connect with public geospatial data and Sentinel/SAR-based flood reference layers.

My interest is not just building apps, but connecting spatial data, status information, and decision-support dashboards into practical systems.
