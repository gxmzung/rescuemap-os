# Open-source Strategy

## 1. Why Open Source?

Disaster response differs by region, school, institution, building, and user group.

A single centralized app cannot fully reflect every local context.

RescueMap OS is designed so each organization can modify:

- disaster protocols
- vulnerable-user support modes
- shelter data
- danger-zone data
- report templates

## 2. Contribution Areas

### Developers

- frontend UI
- backend API
- map layer
- offline sync
- risk scoring
- deployment

### Disaster and Safety Domain Contributors

- fire protocol review
- flood protocol review
- earthquake protocol review
- evacuation behavior review

### Welfare, Nursing, and Emergency-care Contributors

- elderly mode
- disabled mode
- isolated youth mode
- infection-sensitive mode
- guardian check-in flow

### Designers

- emergency UI/UX
- accessibility design
- large button interaction
- high contrast screen
- poster and presentation design

### Public Policy / GIS Contributors

- public data usage
- shelter dataset
- danger-zone dataset
- local government application scenario
