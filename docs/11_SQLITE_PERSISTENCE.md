# SQLite Persistence

## Purpose

RescueMap OS stores incident records in a local SQLite database.

## Stored Information

- Incident ID
- Status
- Disaster Type
- Vulnerable Mode
- Location Clue
- Risk Score
- Check-in Status
- Created Time

## Current Database

backend/data/rescuemap.db

## Future Direction

- PostgreSQL
- PostGIS
- Spatial Query Support
