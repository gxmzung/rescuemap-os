# Product Plan

## 1. MVP Goal

The MVP should prove four things:

1. A user can share status with only three buttons.
2. A user can leave building/floor/zone-based location clues.
3. An administrator can view help requests on a dashboard.
4. Local disaster data can be modified through open data files.

## 2. User Flow

### User App

1. Select disaster type
2. Select optional vulnerable mode
3. Tap one of three status buttons
4. Add location clue if needed
5. Save locally and sync when network is available

### Admin Dashboard

1. View incoming status events
2. Filter by disaster type and vulnerable mode
3. Sort by risk score
4. View map location
5. Mark check-in status
6. Generate failure-map report

## 3. MVP Features

- disaster type selection
- vulnerable mode selection
- 3-button status sharing
- building/floor/zone location clue logging
- shelter and danger-zone map
- admin dashboard
- risk scoring
- failure-map report template
- open-source rescue-kit data files

## 4. Non-goals

The MVP will not include:

- AI-based indoor escape routing
- automatic life-or-death decision making
- medical diagnosis
- rescue success guarantee
- real-time satellite image analysis
- complete BLE/Wi-Fi Direct mesh networking
